# Homeless Help Hub 🏠🤝  
**A Role-Based Full Stack Web Application to connect Users, Volunteers, Donors, and Government Officers**

Homeless Help Hub is a **responsive, secure, and interactive platform** built to help vulnerable communities request support and get connected with the right people—**volunteers, donors, and government authorities**—through a structured verification and approval workflow.

🌐 **Live Website:** https://homelesshelphub.infinityfree.me/  
📦 **GitHub Repo:** https://github.com/ArunChandrasekar07/Homeless_HelpHub.git  

---

## 🚀 What This Project Solves
Many people in need struggle to reach the right help quickly. This platform creates a clear workflow:
- **Users** submit verified help requests
- **Government officers** review/approve requests (region-based accountability)
- **Volunteers** accept tasks and update progress
- **Donors** contribute and track request status transparently

---

## ✅ Key Features

### 👤 User Dashboard
- Submit help requests (with identity/proof)
- Track request and donation status
- View assigned volunteer details
- Communicate/coordinate for support

### 🧑‍🤝‍🧑 Volunteer Dashboard
- Browse approved requests
- Accept assignments
- Update progress/status in real time
- Community engagement workflow

### 🏛️ Government Officer Dashboard
- Verify identity and proof
- Approve/reject requests
- Assign/monitor region-based workflow
- Monitor volunteer activity for accountability

### 💳 Donor Dashboard
- Donate securely to active requests
- Track donation history
- View request progress and impact

---

## 🧰 Tech Stack
- **Frontend:** HTML5, Tailwind CSS, Bootstrap  
- **Backend:** PHP  
- **Database:** MySQL  
- **Core Concepts:** Role-based access, approval workflow, request assignment, status tracking
